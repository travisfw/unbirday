# Unbirday

Unbirday is a fork of Birday, an excellent Android app for upstanding gentlefolk to remember proper birthdays, as God and Nature intended, according to the Gregorian order whose angelic voices sing the virtues of doing the exact same things at the exact same fraction of 365.2425helpimstuckinasolarsystemfactory0982103 days ad infinitum because predictable repetition is GOOD and you definitely want to go to Heaven.  
If that is fine by you, press ctrl-w.

The truth, excellence, and purity of Birday was known, in the Biblical sense, whatever that means.
It was then gutted and bastardized to spew inane reminders and calendar events by their day-of-week and day-of-month.

So there, it is clear:  
If you'd invite cheer  
to a calendeer squeer  
with fewer tears and more beers,  
have no fear.  
Install Unbirday near.

That is: if one was born near a holiday or a time of year when it is otherwise inconvenient to celebrate, check the next *unbirthday* instead.

This fork out-scoped and elided a lot of the [upstream](https://github.com/m-i-n-a-r/birday ) typical birthday tracking features like statistics and age calculation and astrology.
